# Security policy

Use GitHub’s private vulnerability reporting form for security issues affecting the planner, local storage, PDF renderer, or retailer integration. [Report a vulnerability privately](https://github.com/FarnoodF/Shopping/security/advisories/new).

Include the affected commit, the component involved, the observed impact, and enough detail to reproduce the issue with synthetic data. Remove passwords, tokens, login redirects, addresses, and real cart contents from attachments.

For questions about what the local retailer adapter can access, see the [integration security review](docs/security-review.md). Public issues are suitable for general bugs and feature requests.
